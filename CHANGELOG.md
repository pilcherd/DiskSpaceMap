# Changelog

## 1.0.0

First public release.

- Windows disk-space treemap with size-proportional files and folders.
- Automatic drive scanning with live progress and bounded parallel enumeration.
- Immediate-child folder views with unlimited drill-down and breadcrumb navigation.
- Scoped refresh with stable folder layouts, current ancestor totals, and fresh
  root-map click targets after replacing a subtree.
- Explorer integration, hover details, filtering, sorting, and scan diagnostics.
- Startup sizing that accounts for monitor work area and DPI scaling.
- Self-contained, single-file Windows x64 and ARM64 executables.
- Automated scanner, rendering, navigation, refresh, and packaged-runtime checks.
